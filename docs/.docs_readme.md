The Docs-Website is hosted using MKdocs Material and Github Actions.

The github actions definitions are in /.github/workflows/ci.yml. Under "on: push: branches" we define on pushes to what branch the github actions should rebuild the website. The rest is the default configuration by mkdocs.

For the site, we need a "mkdocs.yml" file at the root of the repository to define the site_name, the theme and color scheme, the plugins ("features"), the custom css (extra_css), custom javascript (for LaTeX to render correctly), markdown_extensions (to render icons and stuff), and the nav.

The nav defines the navigation that you can see on the left side of the page. Each row is defined by:

	- Name: {subfolder/}file_name.md

Where Name is the name that is rendered in the sidebar and the file_name.md is the name of the file that gets displayed on that page.

If you want subfolder structures in the sidebar, you'll need to apply that structure in the docs folder. Example:


```
nav:
  - Home: index.md
  - Fundamentals:
      - Overview: fundamentals/start.md
      - Tasks: fundamentals/tasks.md
      - Datasets: fundamentals/datasets.md
      - Fine-tuning: fundamentals/finetuning.md
      - Evaluating: fundamentals/evaluating.md
      - Energy Consumption: fundamentals/energy_consumption.md
  - Platform:
      - Step-by-Step: platform/how_to_use.md
```

All the pages and extra-stuff are located in the /docs folder. "fundamentals" and "platform" are subfolders of /docs. Images that are referenced in the Docs are in the /imgs folder. Extra javascript, like mathjax to render LaTeX is in /javascripts. The color definitions are in extra.css in the /stylesheets subfolder. 

index.md is the default home page that gets displayed when opening the links. 

If you want to test changes locally without having to push to one of the branches every time, you can run "mkdocs serve" in the repo root. You can then access the page under localhost:8000.
